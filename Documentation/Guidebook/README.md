# NavigationKit Guidebook

This guidebook is the complete usage reference for NavigationKit. Start
with the setup guide, then use the focused chapters as the app grows.

1. [Getting started](getting-started.md) — installation, a destination type,
   controller creation, and the native navigation view.
2. [Destinations](destinations.md) — identity, localizable labels, content,
   shared modifiers, and typed links.
3. [Roots and platform placement](roots-and-platforms.md) — fixed roots,
   independent paths, tab/sidebar policies, search roots, and tvOS behavior.
4. [Navigation commands](navigation-commands.md) — selecting roots,
   navigating, returning, replacing paths, and command semantics.
5. [Modal presentations](presentations.md) — nested modal stacks, styles,
   capacity, presentation paths, callbacks, and dismissal.
6. [Custom navigation views](custom-navigation-views.md) — building custom
   tab bars or sidebars on top of the same controller.
7. [Toasts](toasts.md) — typed content, collapsed decks, independent expiration,
   updates, gestures, and hosting across modal presentations.
8. [Migrating to 1.0](migration-to-1.0.md) — the breaking changes from 0.1.x
   and their replacements.

For a compact overview, installation snippet, and minimum platform versions,
return to the [project README](../../README.md). For a working multiplatform
implementation, open `Example App/Example App.xcodeproj`.
